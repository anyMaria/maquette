# HoteBoost — Méga-menu « Fonctionnalités »

Réplique du menu latéral des fonctionnalités HoteBoost (rail de catégories +
liste de fonctionnalités + carte promo), inspiré du centre d'aide Notion.

## Structure
- `index.html` — structure du méga-menu
- `styles.css` — mise en page (grille 3 colonnes), thème corail HoteBoost, responsive
- `script.js` — 5 catégories et leurs fonctionnalités, rendu + bascule au survol/clic

## Aperçu
Ouvrir `index.html` dans un navigateur.

> ⚠️ La catégorie « Ne laissez plus de nuits vides » n'apparaît sur aucune des
> captures fournies : son contenu est un placeholder à confirmer (voir la note
> `⚠️` dans `script.js`).
